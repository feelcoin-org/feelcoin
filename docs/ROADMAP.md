# Feelcoin Public Roadmap

**Project:** Feelcoin (FEEL)  
**Motto:** *In Feels We Trust*  
**Status:** Early-stage independent RandomX Proof-of-Work network  
**Roadmap version:** 5 October 2026

> This roadmap describes current development direction. It is not a promise of fixed dates, market outcomes, exchange listings, or future value.

## Phase I — Network Foundation ✅

Core network and baseline ecosystem established.

- Independent Feelcoin mainnet and genesis
- RandomX Proof-of-Work
- 120-second target block time
- 12-decimal monetary precision
- Feelcoin address namespace
- CLI wallet and wallet RPC
- Linux x64 and Windows x64 builds
- Official mining pool
- Block explorer
- Paper wallet
- Public GitHub organization and repositories
- Versioned binary releases with SHA-256 checksums

## Phase II — Economic & Infrastructure Hardening ✅

Consensus economics and operational infrastructure strengthened.

- Consensus-enforced development treasury from block 590
- 98% of block subsidy to miner/pool
- 2% of block subsidy to development treasury
- 100% of transaction fees retained by miner/pool
- No additional inflation created by the treasury split
- Treasury-aware pool reward accounting
- Treasury-aware explorer display
- Dedicated 0.5% official pool-fee accounting
- Automatic pool payouts
- Systemd service recovery and startup dependencies
- Public graphical pool dashboard
- v0.2.0 release published

## Principles Across All Phases

Feelcoin development follows several standing principles:

- **Open verification:** consensus and economics should be inspectable in source and on-chain.
- **Transparent lineage:** Feelcoin openly acknowledges its Monero-derived technical foundation.
- **CPU-accessible mining:** RandomX keeps general-purpose CPU participation central.
- **No hidden treasury issuance:** the development treasury splits the existing block subsidy.
- **Independent validation:** full nodes, not websites or pools, determine chain validity.
- **No speculative promises:** market price, profitability, adoption, listings, and future supply claims are not guaranteed.
