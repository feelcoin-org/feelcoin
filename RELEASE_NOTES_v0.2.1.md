# Feelcoin Core v0.2.1

Feelcoin v0.2.1 is a networking and bootstrap improvement release.

## Highlights

- Added official Feelcoin mainnet bootstrap nodes.
- New nodes can automatically discover the Feelcoin network.
- Added Node1 and Node2 as initial bootstrap infrastructure.
- Maintains isolation from Monero DNS seed infrastructure.
- No consensus-rule changes.
- No mining algorithm changes.
- No wallet/address format changes.
- No reward or emission changes.

## Official Bootstrap Nodes

- node1.feelcoin.org:35780
- node2.feelcoin.org:35780

## Compatibility

Existing miners connected to the official Feelcoin pool do not need to update.

This release mainly benefits users running their own Feelcoin daemon or full node.
